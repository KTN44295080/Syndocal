# NSIS extension selection

The upstream template is pinned to Tauri CLI 2.5.0: https://github.com/tauri-apps/tauri/blob/tauri-cli-v2.5.0/crates/tauri-bundler/src/bundle/windows/nsis/installer.nsi (MIT).

The reviewed custom template only adds the extension page macro and its initialization call. Hooks are generated by tools/distribution/generate-installer-hooks.mjs. GUI selection and explicit /DJLINK=0 or /DJLINK=1 use the same persisted per-user extensions.ini, independent of project state. Silent updates preserve the supported existing choice; fresh installation defaults to core. Direct MSI has its own DJ Link checkbox (quiet: DJLINK=0/1) and the macOS PKG offers DJ Link/Core choices; Setup I/O has no Extensions editor.

Official custom-template/hook API: https://v2.tauri.app/distribute/windows-installer/
