# Application icon QA - 2026-09-08

## Scope

Syndocal's Tauri application icon now uses the supplied geometric mark as the
canonical app-tile design: the centered white mark on a transparent canvas.
Both the rounded-square background and the opaque black canvas are intentionally
omitted. The shape is represented as deterministic SVG geometry so
the generated raster/icon formats do not depend on image-generation artifacts.
The existing Tauri icon paths in `app/src-tauri/tauri.conf.json` were preserved.

Generated and changed assets:

- `app/src-tauri/icons/app-icon.svg`
- `app/src-tauri/icons/32x32.png`
- `app/src-tauri/icons/128x128.png`
- `app/src-tauri/icons/128x128@2x.png`
- `app/src-tauri/icons/icon.ico`
- `app/src-tauri/icons/icon.icns`
