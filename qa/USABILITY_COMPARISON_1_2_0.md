# Syndocal 1.2.0 usability comparison — 2026-11-05

Task101 documentation checkpoint; inspected `main` **5940b2e87e7c6f788b89484ff8d9a86c45075e41**. Product source was unchanged. This is a browser re-measurement plus a documented competitor comparison. **Native acceptance and `COMPARE-PINNED-001` remain Open.** No measured cross-product usability, latency, reliability or 60fps superiority is claimed.

## Evidence and counting

- **Browser preview (not native):** full application with existing `?syndocalViewportFixture=` harness, isolated `git archive` of the base, Vite on `http://127.0.0.1:5173`, installed headless Edge, Playwright, English/Tally theme, DPR 1, **1920×1080 and 2560×1600 CSS pixels**. Browser plugin not available; existing Playwright dependency was used without installation. Fixtures: `none` (empty project), `vj-bank` (14 layers, 32 slots, existing group/FX), `patch`, `scene-matrix`. Fixture population and navigation between independent scenarios are setup, not operator steps.
- **B** counts one browser click, context click, field commit/selection, slider gesture or shortcut as one interaction. Dropdown selection is one semantic interaction, not a claim that opening and choosing require one physical mouse click. A continuous drag counts once. Characters, scrolling, fixture setup, exploratory/failed locator attempts and automation waits are excluded. A workspace change is **S**; domain/inspector tab changes are **T**; disclosure changes are **D**, counted within B. **M** counts destructive/confirmation modals, not a file chooser, disclosure, context menu or nonmodal inspector. Counts below specify start state and partial endpoints.
- Backend mutations are unavailable in the full-app browser fixture. Selecting a clip changes local selection; Take/Stop/state/catalog/blackout requests reach the UI path and report the disconnected desktop backend. A select element can visually change without authoritative state changing. These are **attempted UI interactions**, not completed playback/output/mapping. Screen detection and four-channel profile selection are disabled at their native authority boundary. No native IPC was fabricated to make a workflow appear successful.
- **Needs native/hardware confirmation:** picker and trusted OS multi-file drop, successful import/Take, canvas commit and preview pixels, displays, MIDI/audio, DMX, external peers, blackout and recovery. No native executable launch, output arming, COM5/serial/device access, OS file drop or synthetic OS input occurred. No installer/download, account, sign-in, key or purchase occurred.
- **Historical native (partial)** and **historical browser + source (partial)** describe the original baselines; they were not rerun. The [10/16 review](COMPETITIVE_REVIEW_2026-10-16.md) and [10/28 audit](../target/qa/ui-usability-20261028/UI-USABILITY-AUDIT.md) did not measure identical complete W1–W8 tasks. Unknown totals stay unknown; no subtraction or percentage speedup across mismatched endpoints.
- Every competitor number is **documented (not hands-on)**. **G** counts the numbered documented action groups reconstructed from official public sources, with compound menu/node operations left within each group. G is **not measured B or a measured click lower bound**. For all competitors, exact clicks, S/T/D, M, median seconds and viewport legibility are unknown. Living manuals do not pin an installed build; no TouchDesigner 2023 build or specific Resolume 7 revision was tested.
- **Median completion seconds: unknown for every complete workflow and every product.** Automation duration is not operator time. The owner checklist supplies the native timing protocol.

The reproducible browser driver, replay script, raw actions/DOM geometry, source-reference audit and competitor research are in [the evidence directory](../target/qa/task101-usability/). `capture-results.json` retains exploratory records and repeated labels; the final replay overwrote each matching PNG. `replay-summary.json` identifies the completed two-viewport pass. Screenshots below use final replay names, not the exploratory `w1-cold-default` image.

## Edition boundaries

Resolume's free demos retain UI features and saving but add a visual watermark and occasional robotic voice; **groups and DMX output are Arena-only**, so Avenue has no equivalent for those rows. [Official edition/demo comparison](https://www.resolume.com/support/en/avenue-arena-difference).

TouchDesigner NC is free for noncommercial work and limits images to **1280×1280**; it cannot establish full-resolution output parity at either UI viewport. Some Commercial/Pro operators are excluded; any future key/account setup belongs to the owner. [NC definition](https://derivative.ca/UserGuide/TouchDesigner_Non-Commercial), [licensing](https://derivative.ca/UserGuide/Licensing).

VDMX6 demo is macOS-only (macOS 13+) and cannot save projects. This task uses ordinary VDMX6 documentation without assuming Plus integrations; no friend's Mac was accessed. [Official product/demo page](https://www.vidvox.net/?f=25), [manual](https://docs.vidvox.net/vdmx/).
