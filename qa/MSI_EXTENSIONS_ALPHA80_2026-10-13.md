# Native MSI extension selection and I/O cleanup — alpha.80

Branch codex/scene-edit-installer-alpha79-20261013; base e626ce82d20f27faed0f5e68670a98c09f98c2c8. Delivered alpha.79 Windows ZIP remains immutable.

The direct MSI now includes a native DJ Link checkbox before the installation directory page. On same-version maintenance, Repair enters this selection page; removal keeps the standard removal route. Initial install defaults to core; supported prior choices preselect during updates. DJLINK=0/1 admits explicit silent installation choices. The app is never started to write installer settings. An embedded first-party Rust action uses the same schema parser as the app, validates existing settings before installation mutations, atomically writes the selected choice, restores prior bytes on rollback, and removes transaction files on commit. All actions run as the installing user and never write settings on uninstall. The ZIP helper delegates MSI choice to the MSI and contains no duplicate choice dialog.

Setup I/O no longer contains an Extensions tab/panel, editor setter, or missing-settings navigation into that panel. Installed DJ Link still gates its actual I/O connection. Scene-edit saved-value behavior from alpha.79 is preserved.
