# 実機UI比較

比較の主張は同じタスク・条件で取得した実物のキャプチャや操作数に基づける。
内部ゲート合格だけでは競合優位の証明にならない。

- 操作前に対象ウィンドウを確認する。Syndocalの最大化などの操作条件は `AGENTS.md` に従う。
- 競合アプリでは保存・破壊的操作・出力実行を行わない。通常の比較操作は選択・
  タブ/ビュー切替・ホバーに限定する。シーンセルや選択対象でも実行を誘発し得るため、
  意味の分からない操作は試さない。必要な意味論は一次資料で確認し、解決しなければ
  その比較項目を未確認とする。作業を進めるのに不可欠ならユーザーに確認する。
- `qa/harnesses/capture-window.ps1` はキャプチャ、`click-window-point.ps1` は
  ウィンドウ相対クリックに使える。利用する環境のUI操作制約を優先する。
- 座標操作は直前キャプチャと現在のウィンドウ位置を対応させる。複数モニタのDPI差で
  ずれた事例がある。スケール変換を確認できなければクリックせず、100%スケールの
  モニタなど座標を検証できる配置を使う。
- キャプチャは `target/qa/ui-comparison/`、比較観察は同ディレクトリの `PRIMARY_OBSERVATIONS.md` の
  該当箇所に記録する。既存の証跡を上書きせず、対象・条件・未確認事項を残す。
